# GDG on Campus JIS University — Community Impact

Public log of what the Google Developer Group on Campus at JIS University builds, runs, and ships. Every event, project, and outcome lives here so the community is verifiable, not just claimed.

## What you'll find

- **[events/](./events/)** — one file per event: topic, speakers, attendance, photos, recording, slides, outcomes
- **[metrics.md](./metrics.md)** — running totals: events, attendees, contributors mentored, projects launched
- **[projects/](./projects/)** — student and community projects spun out of GDG activities
- **[media/](./media/)** — photos, posters, social cards (or links to Drive for large assets)

## About GDG on Campus JIS University

Student-led Google Developer Group chapter at JIS University, Kolkata. We run technical talks, workshops, hackathons, and open-source contribution drives — focused on getting students from "first commit" to "shipping something real."

- **Chapter page:** https://gdg.community.dev/gdg-on-campus-jis-university-kolkata-india/
- **Organizer:** [Ayushman Bhattacharya](https://github.com/Circuit-Overtime) — maintainer at [pollinations.ai](https://github.com/pollinations/pollinations)
- **Org GitHub:** https://github.com/dscjisu

## Get involved

- Want to run a workshop? Open an issue with the `workshop-proposal` label.
- Want to contribute to a project? See [projects/](./projects/).
